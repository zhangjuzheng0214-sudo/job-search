# JobHub 招聘信息聚合平台 · 使用说明

> 帮你把散落在政府官网、国资委、人社局的招聘公告聚合到一起，按**你的学历、专业、地区**精准筛选，不再因为信息差错过报名机会。
> 当前试点城市：**浙江省宁波市**。

---

## 一、这个平台是做什么的

公务员、事业单位、央企国企、劳务派遣/外包的招聘公告，分散在几十个不同的政府网站上，普通人很难逐一关注。

JobHub 做三件事：

1. **自动采集**：每天定时去官方网站抓取最新招聘公告；
2. **AI 解析**：把格式各异的公告（表格、纯文本）用 AI 读成结构化数据（岗位、人数、专业、学历、截止时间）；
3. **精准筛选**：你只需填"我的学历、专业关键词、地区"，立刻看到自己能报的岗位。

## 五、数据采集原理（重要）

政府网站使用 **JPAAS 建站系统**，公告列表不是写死在网页里的，而是打开页面后由后台接口动态返回。

```
步骤 1  调用列表接口
        /api-gateway/jpaas-publish-server/front/page/build/unit
        传入 webId / pageId / pageSize 等参数
        → 返回"公告标题 + 真实相对链接"

步骤 2  拼上域名，得到完整公告地址，逐条抓取详情页

步骤 3  把详情页正文（表格转 Markdown）交给 AI 解析
        → 输出岗位名、人数、专业、学历、报名时间、通用条件

步骤 4  交叉校验后入库（见第八节）
```

## 六、数据库表结构

| 表 | 作用 | 关键字段 |
|----|------|----------|
| `jobs` | 招聘公告主表 | 标题、单位、地区、发布时间、截止时间、总人数、状态、`source_url`（唯一去重） |
| `positions` | 岗位明细 | 岗位名、人数、专业、学历、职责、其他条件（外键关联 jobs） |
| `crawl_logs` | 采集日志 | 采集时间、新增数、更新数、失败数 |

`source_url` 是唯一键，保证同一公告不会被重复收录。

## 七、页面与按钮说明（每个按钮的规则）

### 7.1 类型切换 Tab

```
[ 全部 ] [ 公务员 ] [ 事业单位 ] [ 央企国企 ] [ 劳务派遣/外包 ]
```

- 点击后只显示该类型的公告；"全部"显示所有类型。
- 劳务派遣与外包已合并为一个 Tab（二者含义重叠，不再重复）。

### 7.2 省份 / 城市 下拉

- **省份**：默认选中"浙江"，可正常点击。
- **城市**：选完省份后联动，只列出该省份下的城市，默认"宁波市"。
- 数据范围严格限定在选中的省市，不会出现其他地区的岗位。

### 7.3 我的学历 下拉（核心，以"我"为视角）

选项及可报范围：

| 选项 | 选中后能报的岗位 |
|------|------------------|
| 全部（不筛选） | 所有岗位 |
| 大专 | 大专及以上 / 学历不限 |
| 本科 | 本科及以上 / 大专及以上 / 学历不限 |
| 硕士 | 硕士及以上 / 本科及以上 / 大专及以上 / 学历不限 |
| 博士 | 全部岗位 |

**规则：`我的学历等级 ≥ 岗位要求的最低学历` 才保留。**

- 学历等级：大专=1、本科=2、硕士=3、博士=4、不限=0。
- 例：我是本科，要求"硕士及以上""博士及以上"的岗位被自动排除。
- 岗位写"学历详见原文"（无法确定）的，**默认保留**，避免漏掉。

### 7.4 专业关键词 输入框

- 输入专业关键词，**只在岗位的「专业要求」字段内匹配**（可空格分隔多个词，任一命中即可）。
- 例：输入"环境"，只匹配"环境工程、环境设计、环境科学"等专业要求；
- **不会**匹配任职要求里的"云环境部署""工作环境""办公环境"。
- 支持模糊匹配：输入"环境"即可命中所有含"环境"的专业。

### 7.5 不看（多选，排除类别）

- 下拉内为复选框，可多选，默认不勾选（不排除）。
- 类别（当前仅提供两项）：**教师、医疗卫生**。
- 后端仍保留完整类别标签（财务审计、金融、信息技术、工程技术、法律法务、综合行政、公安警务、科研等），只是前端暂不提供这些排除项，后续可按需开放。
- 类别由 AI 解析时依据岗位名/单位/专业/职责自动归类（一个岗位可有多个标签）。
- **规则**：勾选的类别取并集作为排除集；岗位类别与排除集有任一交集即被过滤。
- 例：勾选"教师"→排除所有教师岗位；勾选"教师+医疗卫生"→两类都排除。
- 排除状态同步到 URL，与其他筛选条件同时生效。

### 7.6 只看正在招聘（开关，默认勾选）

- 勾选：只显示当前在招、且未过截止时间的岗位。
- 取消勾选：才会显示已截止的岗位（带红色"已截止"标识）。
- 判定规则：`status=active` 且（无截止时间 或 截止时间晚于现在）。

### 7.7 排序

- **按截止时间**：离截止越近的排越前面（方便紧急报名）。
- **按招聘人数**：招聘人数多的排前面。

### 7.8 刷新数据 按钮

- 点击后**立即手动触发一次全量采集**，不等定时任务。
- 旁边显示"最后更新时间"。

### 7.9 查看公告原文

- 点击后**新标签页打开**官方网站上的公告原始页面。
- 链接全部来自真实采集，指向招考单位发布的原始公告，不做转载、不伪造。

### 7.10 岗位详情页

- 点击岗位卡片进入，页面**默认滚动到最顶部**。
- 包含：报名信息（发布/截止时间、学历、人数、地点、来源）、岗位与专业要求明细、时效横幅。

## 八、AI 解析与校验规则

### 8.1 通用条件不拆成岗位

"遵守宪法、品行端正、具有国籍"等是**所有岗位通用的报考条件**，单独放在"报考条件"区块，不会被当成岗位。

### 8.2 人数识别（排除干扰）

- 只提取"招聘 / 拟招 / 招录 X 名 / 人"的数字。
- 自动排除：考试"满分 100 分"、成绩百分比、权重、日期、年龄、电话、编号。
- 交叉校验：总人数应与各岗位人数之和一致；不一致以岗位明细为准。

### 8.3 时效徽章颜色

| 状态 | 颜色 | 文案 |
|------|------|------|
| 剩余 > 3 天 | 🔵 蓝色 | 还剩 X 天 |
| 剩余 1～3 天 | 🟠 橙色 | 还剩 X 天（紧急） |
| 已截止 | 🔴 红色 | 已截止 |
| 无法确定 | ⚪ 灰色 | 截止时间不确定 |

> 橙色（快截止）与红色（已截止）明确区分，避免混淆。不再出现"还剩 0 天 0 小时"。

## 九、定时自动采集

- **规则**：距上次成功采集满 24 小时即自动执行（不再卡死凌晨 2 点）。
- **服务启动即检查**：即使服务进程在空闲时被回收，一旦被访问重新启动，也会立即补跑当天的采集。
- 每次采集后自动把过截止的岗位标记为"已截止"。
- 采集记录写入 `crawl_logs`，上次采集时间持久化在数据库，重启不丢失。

## 附：常见问题

**Q：为什么有时显示"截止时间不确定"？**
A：源站可能对服务器限制访问（返回 403），或公告未写明截止日期。提供准确日期后可手动补全。

**Q：为什么点原文看到的排版很怪 / 有大二维码？**
A：那是公告原文里自带的"报名二维码"，在窄屏（手机）上会被放大；电脑浏览器打开即正常。同一网址电脑、手机通用。

**Q：专业搜"环境"为什么结果为空？**
A：说明当前确实没有单位招环境类专业；有新公告时会自动出现。

**Q：如何扩展到其他城市？**
A：在后端新增目标城市的采集源配置即可，筛选、AI 解析逻辑可直接复用。
